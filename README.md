07 Meeting Minutes AI

音声ファイルをアップロードすると、AIが文字起こしを行い、その内容から議事録を自動生成するWebアプリケーションです。

主な機能

音声ファイルのアップロード

音声ファイル形式のチェック

ファイルサイズのチェック（最大25MB）

AIによる音声の文字起こし

文字起こし結果から議事録を自動生成

文字起こし結果と議事録をブラウザに表示

APIエラー時のエラーハンドリング

使用技術

Python

FastAPI

OpenAI API

Jinja2

HTML

CSS

処理の流れ

音声ファイル
↓
FastAPIで受け取り
↓
ファイル形式・サイズチェック
↓
音声データをメモリ上で読み込み
↓
OpenAI APIで文字起こし
↓
生成AIで議事録作成
↓
ブラウザに結果を表示

セットアップ

必要なライブラリをインストールします。

pip install -r requirements.txt

プロジェクト直下に .env ファイルを作成し、OpenAI APIキーを設定します。

OPENAI_API_KEY=your_api_key

.env はGitHubにはアップロードしません。

起動方法

プロジェクトのフォルダで以下を実行します。

uvicorn app.main:app

ブラウザから以下にアクセスします。

http://127.0.0.1:8000

セキュリティ

APIキーは .env で管理します。

.env は .gitignore の対象にします。

アップロードされた音声はアプリ側で永続保存せず、処理時にメモリ上で読み込みます。

ファイル形式とファイルサイズをチェックします。

注意事項

OpenAI APIを利用するため、API利用料金が発生する場合があります。
